This project presents an interactive augmented reality (AR) application that visualizes the Bloch sphere, a critical concept in quantum computing, through an immersive AR interface. Developed using Unity's ARFoundation technology, the application enhances the understanding of qubit manipulation by providing an intuitive and hands-on experience with the Bloch sphere using texture replacement. Aimed at both educational environments and collaborative research, the AR interface promotes deeper engagement through real-time interaction and manipulation, fostering enhanced understanding through visual and spatial learning. By leveraging AR, the tool allows users to experience quantum states in three dimensions, encouraging collaboration between peers and instructors as they can collectively interact with the simulation in a shared space. The flexibility of the Unity engine, combined with the accessibility of mobile AR, enables a broad reach and scalability, positioning the application as a powerful educational resource. This project highlights the strengths of AR in promoting an intuitive and interactive learning experience, which is crucial for complex, abstract concepts like qubit states and quantum mechanics.
